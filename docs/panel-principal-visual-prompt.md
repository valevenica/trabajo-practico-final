# Prompt visual - Panel principal Integra Manufacturing

Diseñar una pantalla principal de escritorio para **INTEGRA MANUFACTURING**, un sistema de gestión integral de inventario, producción y costos. La interfaz debe tener estética industrial premium: fondo claro marfil, acentos borgoña y dorado, tarjetas blancas con bordes dorados finos y sombras suaves.

## Composición esperada

- Barra lateral izquierda angosta en gris metal oscuro, con identidad visual industrial y navegación vertical.
- Encabezado superior amplio con el título **INTEGRA MANUFACTURING** en tipografía serif borgoña y subtítulo en cursiva: **Sistema de Gestión Integral de Inventario, Producción y Costos**.
- Sector superior derecho con el usuario actual y una píldora de estado: **Servidor Fábrica: CONECTADO**.
- Tres tarjetas KPI alineadas horizontalmente:
  - **STOCK CRÍTICO** con píldora **STOCK MÍNIMO (7 items)**.
  - **ÓRDENES DE PRODUCCIÓN** con píldora **EN PROCESO (3)**.
  - **COSTOS TOTALES MES** con valor **$89,450.00**.
- Panel principal con el título **Módulo: Órdenes de Producción** y una tabla oscura de cabecera con columnas: ID ORDEN, PRODUCTO, CANTIDAD, ESTADO, FECHA ENTREGA y COSTO.
- La tabla debe mostrar badges de estado verdes, amarillos y rojos para completada, en proceso y sin stock.
- Botón principal borgoña **Confirmar Orden** y botón secundario contorneado **Generar Reporte**.
- Decoración inferior sutil tipo circuito industrial en color borgoña.

## Paleta sugerida

- Borgoña principal: `#7A1C52`
- Borgoña hover: `#9B2469`
- Dorado industrial: `#B8860B`
- Metal oscuro: `#2E2D30`
- Fondo marfil: `#F8F6F2`
- Cabecera de tabla: `#26262A`
